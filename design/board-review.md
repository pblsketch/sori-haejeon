## 검수 원문

수치는 구현용 CSS px 권장값입니다. 교실 뒷자리 판독은 실제 투사 후 확인이 필요합니다.

| 화면 | 심각도 | 무엇을 어떻게 바꿀지, 구현 수치 포함 |
|---|---|---|
| 전체 — 바다·배 | 중간 | 이어진 등심선은 바다답지만, 회색 배의 작은 질감은 장식처럼 읽히기 쉬움. 배에 **1.5–2px 짙은 윤곽**을 주고 등심선 불투명도는 **15–20%**로 낮춰 정보의 우선순위 확보. 격침 전 조각은 계속 동일하게 유지. |
| 연습 가로 1단계 — 격침 표시 | 중간 | 떨어진 두 조각의 점선·같은 번호는 좋은 정보 연결. 가운데 배 배지는 **40×20px 이상**, 번호는 **20px 이상**, 끌줄은 **2px·점 간격 4–6px**로 강화. 격침은 불탄 질감과 완성된 선체 윤곽으로 함께 표시. |
| 연습 휴대폰 — 소리·축 | **높음** | 번호 **1**이 `/ㄱ/`, `/ㅇ/` 표지의 왼쪽 빗금을 덮음. 번호를 배 조각 옆으로 옮기고 소리 표지와 **4px 이상** 이격. 소리는 **34–38px**, 축 이름은 **16–18px·최대 2줄**로 확보. |
| 연습 휴대폰 — 판 배치 | 중간 | 머리글과 판 사이의 큰 공백이 판을 아래로 밀어 한눈에 살피기 어려움. 판 영역을 위쪽에 정렬하고 상단 여백을 **12–16px**로 제한. 번호·화살표가 차지할 판 바깥 여백도 **12px 이상** 확보. |
| 대결 칠판 — 소리·축 | **높음** | 두 판으로 나뉘면서 특히 축 이름이 작아짐. 1920px 화면에서 각 격자 너비 **560px 이상**, 소리 **48–56px**, 축 **28–32px** 권장. 긴 열 이름은 2줄로 고정. |
| 연습·대결 — 흑백 신호 | 중간 | **◎ / ↔·↕ / × / ∅**로 기본 구별은 가능하지만, ‘같은 줄’의 범위는 보라색 의존이 큼. 같은 줄은 **2px 파선**, 명중은 **2px 실선+◎**로 구별. 기호는 흰 배지에 **휴대폰 18–20px·가로 26–28px**, 획 **2px** 확보. |
| 숨긴 2단계 — 정보 누설 | 중간 | 미발사 칸의 소리·배·빈칸 표식은 보이지 않음. 다만 발사 후 화면이라 **첫 발사 전 동일성은 미확인**. 초기에는 내용별 표식 **0개**, 정답 배치만 바꾼 화면 비교에서 미발사 25칸의 변경 픽셀 **0개**를 검증. 등심선은 정답 배치와 독립시킬 것. |
| 결과 — 소리 지도 | 낮음 | 소리 체계표로 읽기 좋고 황금 표시도 명확함. 배를 다시 넣을 필요는 없음. **‘◎ 이번 판에 맞힌 소리’ 범례 20–24px**를 추가해 황금 칸의 의미를 명시. |

## 검수 뒤 처리

| 지적 | 처리 |
|---|---|
| (높음) 휴대폰: 번호 1이 /ㄱ/·/ㅇ/ 표지의 빗금을 덮음 | 반영: 좁은 판에서는 번호를 표지가 아니라 배 조각 위 가운데에 작게(11px) 둔다. 표지는 가리지 않는다. |
| (높음) 대결 칠판: 두 판으로 나뉘어 축 이름·소리가 작음(격자 560px↑, 소리 48–56, 축 28–32 권장) | 일부 반영: 축 이름 글씨를 칸 너비의 0.22 → 0.3배로(대결 반쪽 판 약 18 → 25px, 칠판 연습 판은 30 그대로). 격자 폭·소리 크기는 대결 화면 배치(css/duel.css, 다른 작업 T19 담당)가 정하는 상자 크기에 묶여 있어 이번 작업 범위 밖 — 남은 과제로 넘김. |
| (중간) 같은 줄 범위가 보라색에 기대 흑백 구별이 약함 | 반영: 같은 줄 범위 윤곽을 2px 파선(최근 3px 파선)으로 — 명중 칸의 실선 황금 테두리와 모양으로도 구별. |
| (중간) 끌줄 배지·번호 크기 | 반영: 끌줄 가운데 배 배지 높이 20px 이상(가로 48px 이상), 칠판에서 번호 약 21px. 배지 안 작은 배는 코드로 그림(그림 파일이 없어도 같다). |
| (중간) 등심선이 배와 경쟁 | 반영: 등심선 불투명도 0.16–0.25 → 0.12–0.18. 배 그림은 이미 짙은 남색 윤곽이 있어 그대로. |
| (중간) 휴대폰 판 위쪽 빈 공간 | 보류: 연습 화면 세로 배치(css/practice.css, T19 담당)가 판을 아래에 붙인다. 판 쪽에서는 담긴 상자 높이에 맞출 뿐. |
| (중간) 숨긴 단계의 쏘기 전 동일성 확인 | 자동 점검으로 확인: 숨긴 단계(자음 2·3, 모음 2) 쏘기 전 모든 칸 모양이 같고 칸 안에 암초·자물쇠·배 조각·물보라가 없음(tests/check-board.mjs 7번). 바다 지도는 칸 밖 한 장이고 정답 배치와 상관없는 고정 그림. |
