### 1회
**현재 상태를 교과서 도해 수준으로 통과시키기는 어렵습니다.** 색과 큰 곡선은 정돈됐지만, 코 통로의 차단·파열 공기의 방향·성대의 단면 표현에 중요한 오류가 남아 있습니다.

좌표는 **첨부 PNG 원본의 왼쪽 위를 (0, 0)으로 한 대략값**입니다. CSS 수치는 실제 화면 표시 기준이며, 애니메이션의 시간 흐름은 정지화면만으로 검증하지 않았습니다.

| 화면/부위 | 심각도 높음·중간·낮음 | 무엇을 어떻게 바꿀지 — 좌표나 수치가 있으면 구체적으로 |
|---|---|---|
| **velar·stopburst·vowel / 코 통로 차단** | **높음** | 구강음인데 여린입천장 뒤로 **코와 입을 연결하는 흰 통로가 남아 있습니다.** velar에서 여린입천장 끝 `(1084,338)`과 인두 뒤벽 사이에 약 **15–20px** 틈이 보입니다. 여린입천장의 **뒤쪽 윗면이 인두 뒤벽에 닿도록** 올려 코 통로를 확실히 닫으세요. 접촉 목표는 대략 `x=1090–1100, y=285–320`입니다. 혀와 여린입천장의 접촉은 별도로 유지해야 합니다. [구강음의 연구개인두 폐쇄 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC6802907/) |

[후두 시상면과 성대 관찰 방향](https://www.schulich.uwo.ca/otolaryngology/undergraduate/undergraduate/the_larynx.pdf#page=21) |
| 전체 / 센입천장–여린입천장 연결·목젖 | 중간 | 여린입천장 시작부 `(868,297–361)`가 수직으로 잘린 덮개처럼 보이고, **목젖이 구별되지 않습니다.** 센입천장의 위·아래 윤곽을 여린입천장 기부로 연속 연결하고, 자유단에는 가늘어지는 목젖을 표현하세요. nasal의 기부 `(865–915,290–335)`도 회전한 사각 조각처럼 보이지 않게 연결 곡선을 다듬으세요. |

### 2회
**높음 2건이 남았습니다.** 콧길 폐쇄·입김 방향·단면의 성대 표현은 개선됐지만, 작은 성대 그림의 상태 구분은 재수정이 필요합니다. 아래는 정지 이미지 7장 기준이며, 애니메이션의 움직임과 시점은 검증하지 않았습니다.

|---|---|---|
| **nasal·vowel / 성대 상태** | **높음** | 비음 /ㄴ/과 모음 /ㅜ/에서도 성문이 거센 파열음처럼 **넓은 삼각형으로 열려 있다.** 발음 상태를 보여주는 그림으로는 성대 진동을 전달하지 못한다. 미리보기에는 서로 가까운 두 성대와 ‘진동’ 표시를, 발음 중에는 작은 틈이 반복해서 여닫히는 모습을 보여 달라. 넓게 열린 그림을 기본 상태로 유지하지 않는다. [성대 진동 설명](https://www.nidcd.nih.gov/health/taking-care-your-voice) |
| **practice-390 / 된 마찰음의 성대** | **높음** | /ㅆ/을 골랐는데 성대가 **틈 없는 한 줄**로 보인다. ‘된소리는 성문을 완전히 닫아서 낸다’는 오개념을 줄 수 있다. 지속적인 마찰 구간에는 공기가 통하는 성문을 보여주고, 긴장은 별도 조임 표시로 표현한다. ‘완전 닫힘’과 ‘긴장’을 서로 다른 상태로 구분해야 한다. [한국어 마찰음의 성문·기류 연구](https://www.eksss.org/archive/view_article?pid=pss-14-3-11) |

| **practice-390 / 잇몸 마찰 틈** | 중간 | 혀끝과 잇몸 사이의 흰 틈이 축소 화면에서 거의 읽히지 않아 비음의 막힘과 비슷해 보인다. SVG의 8단위보다 **윤곽선까지 그린 뒤 실제 화면에 남는 틈**이 중요하다. 휴대폰에서도 표시용 흰 틈이 약 2~3px 남도록 조정하고, 접촉 표시와 겹치지 않게 한다. |
| **vowel / ‘혀 뒤’ 연결선·높이 기준** | 중간 | 연결선은 혀 위 공중의 검은 점에서 끝나고, 실제 초록 선택점까지 닿지 않는다. 선택점도 ‘높은’ 점선보다 아래에 있다. ‘혀 뒤’ 연결선을 초록 선택점까지 잇고, 높이 기준선을 선택점과 일관되게 맞춘다. 현재 검은 점과 회색 점의 중복도 줄인다. |

| **stopburst / 입자와 방출 경로** | 중간 | 입자가 입천장 아래 여러 덩어리로 떠 있어, 막힌 곳에서 풀려 입 밖으로 나가는 관계가 약하다. 방출된 접촉부에서 입술까지 이어지는 분포를 만들고, 입술 바깥에도 작은 입자를 배치한다. 호에는 ‘강한 입김’ 표시를 보태면 음파와 혼동하는 일을 줄일 수 있다. |

| 전체 / 선·색·이름표 | 낮음 | 혀 안 선 제거, 평평한 앞니 끝, 둥근 목젖과 잎 모양 후두덮개는 이전보다 명료하다. 살빛 조직·붉은 혀·흰 통로의 구분과 큰 이름표도 적절하다. **practice-1280·390의 표머리 ‘입술’만 카드·단면의 ‘두 입술’로 통일**하면 대응이 더 쉬워진다. |

**2회 뒤 처리**: 비음·유음·모음(울림소리)은 두 성대가 모여 떨고 양옆 물결, 파열·파찰·마찰은 성문 열림 · 된소리는 성문을 닫지 않고 좁히며 조임 표시(완전히 닫힘은
