# 보안·개인정보 정책

## 지키는 것

- **학생의 개인정보를 받지 않는다.** 이름·학번·반·계정·로그인이 없다. 화면에 입력 칸(글을 쓰는 칸)이 없다. 결과 제출은 학생이 결과 화면을 캡처해 따로 낸다.
- **네트워크로 아무것도 보내지 않는다.** `fetch`는 같은 출처의 음원 파일(`assets/audio/*.mp3`)을 받는 데에만 쓴다. 분석·광고·오류 보고 스크립트가 없다.
- **인터넷에서 아무것도 불러오지 않는다.** 글꼴(woff2)·그림(webp)·음원(mp3)·스크립트·CSS는 모두 저장소에 동봉한다. 외부 CDN·Google Fonts 링크를 넣지 않는다 — 넣으면 학교망이 막았을 때 화면이 깨지고, 학생 접속 기록이 제3자에게 간다.
- 학교 기기를 여러 학생·반이 함께 쓴다. 그래서 결과 화면은 **이번 판만** 보여 주고, 누적 기록은 '이 기기의 소리 지도'로 따로 둔다.

## 권한 모델

권한 구분이 없다. 교사용 화면·교사 비밀번호·`?teacher=1` 같은 숨은 주소·주소로 미리 설정하는 값이 **없다**(선생님 결정: 학생이 직접 고른다). 누구나 모든 화면과 '기록 지우기'를 쓸 수 있다.

| 누가 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|
| 기기를 쓰는 누구나 | 모든 모드·단계, 설정 변경, 그 기기의 기록 지우기 | 다른 기기의 기록 보기·지우기(기기 밖으로 나가는 기록이 없음) |

## 기기에 남는 것(localStorage, 이름 앞에 `sori-haejeon:`)

| 이름 | 내용 | 민감도 | 지우는 방법 |
|---|---|---|---|
| `settings` | 배경 음악·효과음 켜기와 음량, 움직임 줄이기 | 없음 | 브라우저 사이트 데이터 삭제 |
| `selection` | 마지막 학년·바다·단계·숨기기 시간 | 없음 | 브라우저 사이트 데이터 삭제 |
| `soundmap` | 이 기기에서 맞힌 적 있는 소리 목록(자음·모음), 더한 판 수, 이미 더한 판 표시(최대 200개) | 없음(사람과 연결되지 않음) | 설정 → 기록 지우기 |
| `seenExample` | 풀이 예시를 본 적 있음 | 없음 | 설정 → 기록 지우기 |
| `game` | 진행 중인 판(함대·쏜 기록) | 없음 | 설정 → 기록 지우기, 또는 판이 끝나면 저절로 |

- 저장이 막히거나(사생활 보호 모드·저장소 차단) 값이 망가져도 게임은 기본값으로 돈다. 저장 오류를 화면에 띄우지 않는다.
- 숨긴 함대가 진행 판에 평문으로 들어 있다. 개발자 도구로 볼 수 있지만 성적과 무관한 수업 게임이라 감추지 않는다. 다만 **화면 글·DOM·aria에는** 숨긴 단계의 답이 새지 않아야 한다(학생이 화면만으로 추론하게 하려는 학습 설계).

## 출처 표기 의무

- 배경 음악: Kevin MacLeod 2곡(CC BY 4.0), Scott Buckley 1곡(CC BY 4.0) — **출처 표기가 조건**이다. 게임 안 '만든 사람·출처' 화면, README, `assets/audio/CREDITS.md`에 곡명·만든 사람·라이선스를 적는다. 곡을 바꾸거나 더하면 세 곳을 함께 고친다.
- 효과음: Freesound의 CC0(표기 의무 없음, 감사 표기는 함).
- 글꼴: Hahmlet·Pretendard(SIL OFL 1.1). 부분 글꼴은 수정본이라 원래 이름을 쓰지 못해 `SoriTitle`·`SoriUI`로 이름을 바꿨다. `assets/fonts/OFL-*.txt`를 함께 배포한다.
- 생성 그림: 이 게임을 위해 새로 만든 것. 프롬프트를 `assets/prompts.md`·`tools/prompts/`에 남긴다.
- 새 외부 파일(음원·글꼴·그림 등)은 **선생님 승인 없이 내려받지 않는다.** 음원은 후보(곡명·출처·라이선스·용량·들어 볼 주소)를 보여 드리고 고른 것만 받는다. 교육용 공개 배포가 되고 조건을 지킬 수 있는 라이선스만 후보로 올린다.

## 배포 계정

GitHub `pblsketch` 계정의 공개 저장소 + Pages. 저장소 커밋 작성자도 저장소 설정의 `pblsketch`(noreply 주소)다. 원격에 올리거나 저장소를 만들기 전에는 **선생님께 저장소 이름·공개 여부를 확인받는다.** 비밀 값(토큰·키)은 저장소에 두지 않는다 — 게임에 필요한 비밀 값이 없다.
