# 0009 판 = 섬과 암초 바다 지도 + 위에서 본 배 조각

## 배경
처음 판은 체계표 칸만 있고 배 그림은 판 옆 목록에만 두었다(떨어진 칸에 걸친 두 칸 배 /ㅂ/·/ㅁ/ 등이 이어진 배 모양이 안 되기 때문). 선생님이 "바다가 바다 같지 않고 배가 장식 같다"며 다시 디자인하자고 해 시안 세 가지 중 C(섬과 암초 바다 지도)를 골랐고, 떨어진 두 칸 배는 점선 끌줄과 번호를 **둘 다** 쓰기로 했다.

## 결정
판 전체가 하나로 이어진 바다 지도(등심선·잔물결) 위에 얇은 체계표 격자와 소리 표지. 명중 칸에는 위에서 본 배 조각이 드러나는데, 가라앉기 전에는 모든 배가 같은 가운데 조각이다. 격침되면 제 모양(한 칸 배, 칸 안에 세운 세 칸 배, 뱃머리·가운데·배꼬리, 떨어진 두 칸 배는 끌줄 + 같은 번호)과 불탄 그림. 빈칸을 쏘면 암초.

## 버린 것
- 판에 배를 그리지 않기: 선생님이 배가 장식 같다고 했다.
- 명중 때부터 크기별 조각: 배 크기가 새어 추론이 필요 없어진다.
- 표의 줄 순서를 바꿔 두 칸 배를 붙이기: 교과서 체계표 순서가 깨진다.

## 결과
숨긴 단계에서 암초·조각 모양이 쏘기 전에 드러나면 안 된다는 불변 규칙이 생겼다. 그림은 `top_*.webp`(생성 + 후처리)이고 없으면 코드로 그린다. 좁은 휴대폰 칸에서는 표지·배지·조각이 겹칠 여유가 적다.
