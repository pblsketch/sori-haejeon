# 0002 ES 모듈 대신 일반 스크립트 + 전역 G(빌드 없음)

## 배경
출발점 기획안은 모듈 방식 예시였다. 같은 시리즈의 다른 게임(도산십이곡 등)은 일반 스크립트로 되어 있고, 선생님은 `index.html` 더블클릭으로도 열리는 것을 원했다. ES 모듈은 file://에서 CORS로 막힌다.

## 결정
빌드 도구 없이 일반 `<script>`를 순서대로 읽고, 모든 모듈은 `window.G` 아래 이름 하나를 연다. 데이터는 `window.SOUNDS` 같은 전역 상수.

## 버린 것
- ES 모듈: file://에서 안 열린다.
- 번들러(Vite 등): 선생님이 직접 고치고 올리기에 단계가 늘고, 시리즈의 다른 게임과 달라진다.

## 결과
의존 방향은 `index.html`의 등록 순서로만 지켜진다(도구가 막아 주지 않음). 새 파일은 층 순서에 맞게 손으로 등록한다. Node 점검은 `vm`으로 스크립트를 한 컨텍스트에 차례로 읽는다(최상위 `const`는 보이지 않으므로 데이터는 `window.`로 내보낸다). 이름 충돌을 막는 것은 `G.<이름>` 관례뿐이다.
