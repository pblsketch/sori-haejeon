# 0003 브라우저 점검 도구는 aside

## 배경
실제 브라우저에서 끝까지 풀기·화면 크기별 캡처·동시 터치를 확인해야 한다. 선생님이 브라우저 점검 도구로 aside를 지정했다.

## 결정
모든 브라우저 점검은 `aside repl`로 정해진 대본을 돌린다(`tests/aside.mjs`). 규칙·저장·문구·음원은 브라우저 없이 Node로 점검한다. 학생 관점 검토는 `aside exec` 에이전트에게 맡긴다.

## 버린 것
- Playwright/Puppeteer: 선생님이 aside로 정했다. 외부 npm 패키지와 브라우저 내려받기도 필요 없어진다.

## 결과
aside의 성질에 맞춘 방식이 굳었다: 종료 코드가 늘 0이라 출력의 `PASS`/`FAIL` 표시로 판정, 화면 크기를 못 바꿔 `tests/pages/frame.html`의 iframe으로 크기별 점검, 콘솔 이벤트가 안 와 게임이 `window.__soriErrors`에 오류를 모음(그래서 게임 코드의 `console.error`는 점검 실패), 호출 한 번 120초·evaluate 30초 제한으로 대본을 조각냄. 점검을 돌리려면 Aside 앱이 켜져 있어야 하고 전체 점검이 약 30분 걸린다. 진짜 칠판의 동시 터치·성능은 이 방식으로 확인할 수 없다.
