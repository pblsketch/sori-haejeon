# 0008 고르기는 모두 아래 조작부, 단면도는 보여 주기 전용

## 배경
처음에는 입안 단면도의 자리를 눌러 조음 위치를 고르고, 방법·세기만 아래 카드로 골랐다. 선생님이 "구강 구조 그림이 조악하고, 조음 위치·조음 방법·소리의 세기 세 가지가 모두 하단에 있어야 한다"고 했고, "한 화면에서 선택해야 되는 것들을 한 번에" 보여 주길 원했다.

## 결정
① 위치 ② 방법 ③ 세기(모음 ① 높이 ② 앞뒤 ③ 입술)를 모두 아래 조작부에 한꺼번에 보이고, 줄마다 한 번 누른 뒤 발사한다(단계적으로 여는 방식 없음). 단면도는 누르는 자리가 없는 보여 주기 전용으로 바꾸고 교과서 도해 수준으로 다시 그렸다. 발사하면 고른 자리·방법대로 조음 기관이 실제로 움직인다. 휴대폰은 단면도와 바다를 위아래 반반.

## 버린 것
- 단면도를 눌러 위치 고르기: 위치만 다른 곳에서 고르니 흐름이 끊기고, 휴대폰에서 위아래를 오가야 한다.
- 한 줄씩 차례로 여는 조작: 한 화면에서 모두 보이게 하라는 요구와 어긋난다.

## 결과
단면도는 조작부의 선택을 받아 모양만 바꾼다(부품끼리는 화면 모듈이 엮음). 단면도의 자리 이름을 숨기는 단계에서도 조작 카드 이름은 늘 보인다. 판의 칸도 누르는 곳이 아니어서, 처음 보는 학생이 칸을 눌러 보는 일이 있다(도입에서 한마디로 해결).
