# 0005 /ㅎ/은 세기 없음으로 채점

## 배경
교과서마다 /ㅎ/의 세기 자리가 다르다(거센소리로 두는 책, 세기 구분 밖으로 두는 책). 한쪽으로 채점하면 다른 교과서를 쓰는 반에서 정답이 오답이 된다.

## 결정
/ㅎ/ = 목청 + 마찰 + 세기 없음. 목청 + 마찰을 고르면 세기 카드가 흐려지고 세기 없이 쏜다.

## 버린 것
- /ㅎ/을 거센소리로: 일부 교과서와 어긋난다.
- 학년·교과서별 설정: 선생님 기능·설정을 늘리지 않는다는 원칙과 부딪힌다.

## 결과
자음 1단계(세기 카드 없음)의 9칸에는 /ㅎ/이 없고, 1단계에서 목청 + 마찰은 '이번 바다에 없는 칸'(턴 안 씀)이다. 한 칸 배 묶음에 /ㅎ/이 있고, 세 칸 배(세기만 다른 셋)에는 /ㅎ/이 들어갈 수 없다.
