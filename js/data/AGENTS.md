# js/data — 학습 데이터와 화면 문구(선생님이 고치는 곳)

## 맡는 것
- `sounds.js`(`SOUNDS`): 자음 19·단모음 10의 자질, 자질 키 목록, '알아 두기' 조건(`notes`). **채점의 진실.**
- `fleets.js`(`FLEETS`): 바다·배 크기별로 숨을 수 있는 소리 묶음.
- `levels.js`(`LEVELS`): 단계마다 열린 칸, 세기 카드 유무, 보이는 것(`show`), 같은 줄 강조, 도움(따라 해 보기·풀이 예시), 함대 구성, 제한 턴.
- `text.js`(`TEXT` + `G.text`): 화면에 나오는 모든 문구 — 학년별 용어(긴 이름·짧은 이름), 신호·안내 한 줄, 따라 해 보기 29줄, 풀이 예시 대본, 알아 두기, 생각해 볼 질문(학년 × 바다), 단추 이름, 대결 안내.
- `mouth.js`(`MOUTH`): 입안 단면도의 좌표·모양 경로, 방법·세기별 흐름 규칙(막음 표시·콧길 문·입자 움직임), 조음 동작 시간표, 조정값.

## 맡지 않는 것
- 규칙 계산(채점·신호·배치): `G.rules`. 여기에는 **값만** 둔다.
- 그리는 코드: 단면도 그리기·애니메이션은 `js/game/mouth.js`, 문구 배치는 화면 모듈.
- `G.text` 도우미 함수(파일 맨 아래)는 다른 코드가 쓰는 공개 모양이다. 문구만 고칠 때는 건드리지 않는다.

## 불변 조건
- 소리 id는 자모 한 개(`'ㄱ'`), 빗금 없이. 화면 문구 안의 소리는 **언제나 `/ㄱ/`** 빗금 표기.
- `sounds.js`에는 화면 이름을 두지 않고 자질만 둔다(다음 편 음운 변동 게임이 자질로 가져다 쓴다).
- /ㅎ/은 `strength: 'none'`. 모음은 단모음 10개(/ㅚ/·/ㅟ/ 포함), 저·앞·원순과 저·뒤·원순은 빈칸.
- 배 묶음 안 소리 순서 = 저장·표시 순서(세기 예사→된→거센, 모음 높이 순). 순서를 바꾸면 저장된 진행 판의 배와 어긋날 수 있다.
- `LEVELS[바다][단계].fleet`은 큰 배부터. 자음 1단계 `open`에는 /ㅎ/이 없다(9칸). 학년 분기를 두지 않는다.
- `text.js`: `m3`·`h1`은 같은 키 구조. 금지 낱말(글자, 훈민정음, 해례, 제자 원리, 상형, 가획, 중세, 조선 수군, 판옥선·협선·척후선, 게임오버)이 문구와 **파일 어디에도**(주석 포함) 없어야 한다. 문구는 한 줄, 대략 30자 이내. 따라 해 보기는 29개 소리 모두. 풀이 예시는 세 발·세 줄 이내이고 각 발의 `expect`(기대 신호)가 실제 규칙과 맞아야 한다.
- `mouth.js`: `DURATION` ≤ 1500(ms). 흐름 규칙 표(파열·파찰·마찰·비음·유음·된·거센·모음)는 조음 음성학 내용 그대로다 — 모양 때문에 규칙을 바꾸지 않는다.
- 모든 파일은 `window.이름 = …`으로 내보낸다(최상위 `const`는 Node 점검에서 보이지 않음). DOM을 쓰지 않는다.

## 구현 방식
- 조정값: `LEVELS`의 `turns`·모음 `fleet`, `MOUTH.PARTICLES`(거센소리는 두 배)·`DURATION`·`TONGUE_MS`·`NEAR`. 교실에서 해 본 뒤 선생님 말에 따라 바꾼다.
- `TEXT`의 `{이름}` 자리는 `G.text.fill`이 채운다. 학년별 이름은 `G.text.term`(긴 이름)·`G.text.short`(카드·판 머리). 모르는 학년 값은 중3으로 본다.
- 결과 화면 음원 출처는 `js/game/app.js`의 목록에 있다(`TEXT.credits.lines`를 채우면 그 앞에 더 보인다).

## 점검
- `node tests/check-text.mjs`: 29개 소리의 따라 해 보기, 금지 낱말(문구 + 파일), 빗금 표기, 풀이 예시 세 줄·기대 신호, 학년 키 구조.
- `node tests/check-rules.mjs`: 소리표·배 묶음·단계가 규칙과 맞음.
- 문구를 고치면 `npm test -- screen-text`(실제 화면 글), 새 음절이면 `python tools/build_fonts.py`.
